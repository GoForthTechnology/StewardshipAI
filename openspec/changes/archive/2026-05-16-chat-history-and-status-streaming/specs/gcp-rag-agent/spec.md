## MODIFIED Requirements

### Requirement: User-Identified Interaction
The agent SHALL support associating queries with a verified user identity (email) and conversational context (history) for audit logging and contextual response generation.

#### Scenario: Generating Response with History
- **WHEN** a query is submitted with an associated history of previous messages
- **THEN** the agent SHALL utilize both the history and the RAG corpus to generate a contextually relevant response.
- **AND** the agent SHALL yield periodic status updates (e.g., "Searching...") before yielding the final response text.

## ADDED Requirements

### Requirement: Automated Chat Titling
The system SHALL provide an endpoint to generate concise, human-readable titles for chat sessions based on initial user input.

#### Scenario: Generating a Summary Title
- **WHEN** the titling endpoint is called with a user prompt
- **THEN** it SHALL return a 2-4 word summary (e.g., "Tithing Guidance") generated by the LLM.
