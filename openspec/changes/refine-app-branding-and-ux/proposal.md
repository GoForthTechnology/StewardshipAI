## Why

The current branding and styling of the Stewardship AI Portal are functional but lack visual polish and brand consistency. Updating the title, favicon, and adding subtle UX enhancements will create a more professional and modern experience for users.

## What Changes

- **Branding Update**: Update the application name to "Stewardship Portal" consistently across the UI.
- **Favicon Update**: Replace the default favicon with the dove icon used in the side panel for better visual continuity.
- **Header Refinement**: Improve the styling, typography, and spacing of the main application title and header area.
- **UX Polish**:
    - Add smooth transition animations for the sidebar opening and closing.
    - Implement hover states for navigation items and interactive cards.
    - Refine component spacing and alignment for a more balanced layout.

## Capabilities

### New Capabilities
- `ux-polish`: Requirements for animations, interactive states (hover), and general layout refinements to enhance the user experience.

### Modified Capabilities
- `web-interface`: Update requirements for the application title styling and favicon implementation.
- `generic-branding`: Update the official application name requirement.

## Impact

- **Frontend**: `frontend/src/index.html`, `frontend/src/app/app.html`, `frontend/src/app/components/*`, and global CSS files.
- **Assets**: `frontend/public/favicon.ico` (or equivalent).
