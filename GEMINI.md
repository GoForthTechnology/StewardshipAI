# Project Instructions: StewardshipAI

This document outlines the core engineering standards, architecture, and workflows for the StewardshipAI project.

## Core Mandates

- **Source Lockdown**: All agents MUST be grounded in a RAG corpus. Never allow hallucination or use of outside knowledge.
- **Citation Enforcement**: Every response generated by an agent MUST include citations to the source material.
- **Credential Protection**: Never commit API keys or Service Account JSON files. Use Application Default Credentials (ADC) for all GCP interactions.
- **Traceability Firewall**: NO change SHALL be pushed to `main` if it decreases the OpenSpec scenario coverage baseline. Every new requirement MUST be accompanied by a corresponding automated test.

## Architecture

- **Modular Agents**: Implement agents as classes in `rag_agent.py`. They should be decoupled from configuration.
- **Type-Safe Configuration**: Use `config.py` and `pydantic` to manage all environment-driven configurations.
- **Platform-Native**: Design all components to be compatible with GCP deployment (Cloud Run, Vertex AI Agent Platform).

## Workflows

### Quality & Traceability Workflow
- **Verification**: Run `python3 verify_coverage.py` before every push.
- **Baseline Updates**: When coverage increases, formalize the new floor by running `python3 verify_coverage.py --update-baseline`.
- **Pre-Commit Audit**: Use `./pre-commit.sh` to verify that modified specifications are fully covered before committing.

### Terraform Workflow
- **Variables**: Always use the local `deploy.tfvars` file for all Terraform operations.
- **Commands**: 
  - `terraform plan -var-file=deploy.tfvars`
  - `terraform apply -var-file=deploy.tfvars`

## Code Style

- **Python**: Use Python 3.10+ features (type hints, async/await).
- **Naming**: `snake_case` for files and variables, `PascalCase` for classes.
- **Documentation**: Provide docstrings for all public classes and methods.

## Environment Variables

- `GCP_PROJECT_ID`: Target GCP project ID/number.
- `GCP_LOCATION`: Vertex AI region (e.g., `us-south1`).
- `GCP_RAG_CORPUS_ID`: The resource name of the RAG corpus.
- `GOOGLE_CLOUD_API_KEY`: (Optional) Fallback API key.
